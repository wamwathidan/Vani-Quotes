# Vani-Ashraya | Devotional Quote Card Generator

Vani-Ashraya is a lightweight, responsive Progressive Web App (PWA) designed to generate beautiful, customizable quote cards for spiritual discourses and lectures.

## Features

* **Customizable Themes:** Choose between traditional saffron, parchment, dark devotional, ethereal, and modern editorial styles.
* **Auto-Fitting Text Engine:** Dynamic font scaling ensures quote text always fits inside card boundaries without overflowing.
* **Pre-configured Photo Presets:** Built-in photo selectors for HDG Srila A.C. Bhaktivedanta Swami Prabhupada and HH Maha-Vishnu Swami Maharaj, plus support for custom image uploads.
* **Export & Share:** Download high-resolution PNG quote cards or share directly via mobile Web Share API.
* **Offline-Ready PWA:** Installable directly on desktop or mobile home screens with offline access powered by a Service Worker.
